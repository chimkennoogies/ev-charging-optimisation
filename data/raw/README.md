# Data Directory

Place your `ev_charging_data.csv` file in this directory.

## Expected CSV Format

The CSV file should contain the following columns:

- User ID
- Vehicle Model
- Battery Capacity (kWh)
- Charging Station ID
- Charging Station Location
- Charging Start Time
- Charging End Time
- Energy Consumed (kWh)
- Charging Duration (hours)
- Charging Rate (kW)
- Charging Cost (USD)
- Time of Day
- Day of Week
- State of Charge (Start %)
- State of Charge (End %)
- Distance Driven Since Last Charge (km)
- Temperature (°C)
- Vehicle Age (years)
- Charger Type
- User Type

## Note

This is a synthetic dataset for educational and ML implementation purposes only.
